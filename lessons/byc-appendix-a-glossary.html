Appendix A: Glossary

CTCHHOYED Team14 Nov 2026
Term Meaning
API A set of rules that lets two programs communicate.
APK / AAB Android app package files.
Backend The server side of an app: logic, database, security.
Bug A mistake in code.
Compiler Translates source code into machine code.
Cross-platform One codebase for several operating systems.
Database Organized storage of data.
Debugging Finding and fixing bugs.
Frontend The part users see and use.
Framework A ready-made toolkit for building apps faster.
Git Version control system for tracking code changes.
HTTP The protocol browsers and servers use to communicate.
IDE Integrated Development Environment: an editor with extra tools.
JSON A text format for sending structured data.
Native app An app built with the official tools of one OS.
OOP Object-oriented programming.
OS Operating system.
PWA Progressive Web App.
SDK Software Development Kit: tools and libraries for a platform.
Server A computer that provides services or data to clients.
SQL Language for working with relational databases.
UI / UX User interface / user experience.
Widget A building block of a Flutter screen.
