Repeat with loops

CTCHHOYED Team12 Nov 2026

A loop repeats code so you don't write it many times.

Syntax

for (start; test; step) {
    // repeated code
}

while (test) {
    // repeated code
}

break leaves the loop. continue skips to the next round.

The for loop

for (int i = 1; i <= 5; i++) {
    System.out.println("Number " + i);
}

It has three parts: start, condition, step.

The while loop

int count = 3;
while (count > 0) {
    System.out.println(count);
    count--;
}
System.out.println("Go!");

If the condition never becomes false, the loop never ends.

Use break to leave a loop early and continue to skip to the next round.
