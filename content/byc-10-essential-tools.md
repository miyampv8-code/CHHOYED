These skills are not glamorous, but every professional developer uses them daily.

## 10.1 Git and GitHub

Git records every version of your code so you can go back and work with others. GitHub is a website that stores Git projects online and acts as your public portfolio.

```bash
git init            # start tracking a project
git add .           # select changes
git commit -m "first version"
git push            # upload to GitHub
```

## 10.2 Command line (terminal)

Typing commands is often faster than clicking. Learn `cd` (change folder), `ls` or `dir` (list files), `mkdir` (make folder) and how to run tools like Git, Node and Flutter.

## 10.3 Code editors and IDEs

| Tool | Used for |

## 10.4 Databases and SQL

Nearly every app stores data. Learn the basic SQL commands: `SELECT`, `INSERT`, `UPDATE`, `DELETE`, and how tables relate through keys.

## 10.5 More skills

- **APIs and JSON:** request and read data from servers.
- **UI/UX basics:** simple layouts, readable text, good colors. Figma is a free design tool.
- **Debugging:** read error messages calmly; search the exact message online.
- **Testing:** check your code works before users find bugs.
- **Security basics:** never store plain passwords; never publish secret keys; ask for only needed permissions.
- **Publishing:** Google Play Console, Apple App Store Connect, web hosting.
- **English reading:** most documentation and error messages are in English.
- **Soft skills:** asking good questions, teamwork, time management.
