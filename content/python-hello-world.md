Python is a beginner-friendly language used for websites, data, AI and automation. Its code is short and easy to read.

## Your first program

```python
print("Hello, World!")
```

## How it works

- `print` shows text on the screen.
- Text goes inside quotes, either `"double"` or `'single'`.
- Python has no `;` and no `main`. The program simply runs from the top line to the bottom.

## Comments

```python
# Python ignores this line
print("Hello")  # You can also comment after code
```

## Run it

Install Python from python.org and save the code as `hello.py`. In a terminal run `python hello.py` (on some computers it is `python3 hello.py`).

> Python uses **indentation**, the spaces at the start of a line, to group code. You will see this in lesson 4.
