Before starting a language or framework, you should be able to answer "yes" to each item below.

- I can explain hardware, software and the role of an OS.
- I know the difference between Android and iOS and how apps reach users.
- I can compare web apps, native apps, cross-platform apps and hybrid apps.
- I can describe frontend, backend, database and API using an example.
- I understand variables, conditions, loops, functions and basic OOP.
- I know why Kotlin replaced Java as the main Android language and what Flutter offers.
- I have installed Git and created a GitHub account.
- I have chosen a learning path and a first project.

> **Key idea**
> If you can tick most boxes, you are ready. Open your editor, start your chosen path and build something today.
