## Your first program

```python

```

`print` shows text on the screen. Text goes inside quotes.

## Variables

A variable is a name that stores a value.

```python
name = "Dara"
age = 16
print(name, "is", age, "years old")
```

## Try it

Change `name` and `age` to your own, then run the program again.
