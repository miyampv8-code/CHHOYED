Java is a popular language used for Android apps, websites and games. Every Java program lives inside a **class**.

## Your first program

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## How it works

- `public class Main` creates a class named Main. The file must be called `Main.java`.
- `main` is where the program starts.
- `System.out.println` prints a line of text. Every statement ends with `;`.

## Run it

Install the JDK, then in a terminal run `javac Main.java` and then `java Main`.

## Try it

Change the text so the program prints your name on two lines.
