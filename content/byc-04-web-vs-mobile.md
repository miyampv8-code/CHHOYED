Developers build for two main environments: the web (opened in a browser) and mobile (installed on a phone). Each has strengths.

| | Web | Mobile app |
|---|---|---|
| Runs in | A browser (Chrome, Safari, Edge) | Installed on the phone |
| Installation | None; open a link | Download from a store |
| Internet | Usually required | Can work offline |
| Phone features | Limited (camera, location with permission) | Full access |
| Updates | Instant; update the server | User must update the app |
| Main languages | HTML, CSS, JavaScript | Kotlin, Swift, Dart, JavaScript |
| Reach | Any device with a browser | Per platform (Android, iOS) |
| Speed and feel | Good, depends on the browser | Best, especially native |

## 4.1 Website vs. web app

- **Website:** mainly shows information. Examples: news pages, school pages, company pages.
- **Web app:** interactive and works with user data. Examples: Gmail, Facebook, Google Docs, online shops.

## 4.2 The three building blocks of web pages

| Technology | Job | Analogy |
|---|---|---|
| HTML | Structure and content (headings, text, images, buttons) | The skeleton of a house |
| CSS | Style: colors, fonts, layout, animations | Paint and decoration |
| JavaScript | Behavior and logic (clicks, forms, data) | Electricity and plumbing |

## 4.3 PWA: a bridge between web and mobile

A Progressive Web App (PWA) is a web app that can be added to the phone's home screen, work partly offline, and send notifications. It is a cheaper way to give users an app-like experience.

## 4.4 How to choose

| If you need... | Choose |
|---|---|
| Fast launch, wide reach, easy updates | Web / PWA |
| Camera, GPS, notifications, offline use, top performance | Mobile app |
| Both Android and iOS from one team | Cross-platform (Flutter / React Native) |
