Many beginners open a code editor on day one and quickly feel lost. They do not yet know what an operating system is, why an Android app cannot run on an iPhone, or what the words frontend, backend and API mean. This book fixes that problem.

It is a foundation guide. Before you learn HTML, Kotlin or Flutter, you will build a clear mental map of the whole software world: how computers work, which operating systems exist, how websites differ from mobile apps, how apps are structured, and which language or framework fits which goal.

**BEFORE YOU CODE: The Foundation Guide for Future Web and Mobile App Developers.** Computers, Operating Systems, Web vs Mobile, App Types, Java, Kotlin, Flutter. A student handbook and learning roadmap.

## Who this book is for

- Students who want to become web developers or mobile app developers.
- Teachers who need a clear, ordered class handout.
- Self-learners who feel confused by too many tools and trends.

## How to use this book

1. Read the chapters in order. Each one builds on the last.
2. Study the tables and diagrams; they summarize the main ideas.
3. Answer the Review Questions at the end of each chapter before moving on.
4. Finish with the roadmap in Chapter 11 and choose your learning path.

> **Key idea**
> You do not need to memorize everything. You need to understand the big picture so that every new tool you learn later has a place in your mind.
