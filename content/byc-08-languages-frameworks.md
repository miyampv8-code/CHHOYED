A programming **language** is the way you write instructions. A **framework** is a ready-made toolkit built with a language to speed up work. For example, Dart is the language and Flutter is its framework.

| Goal | Languages | Frameworks and tools |
|---|---|---|
| Web frontend | HTML, CSS, JavaScript, TypeScript | React, Vue, Angular, Tailwind CSS |
| Web backend | JavaScript, PHP, Python, Java, C# | Node.js, Laravel, Django, Spring Boot, ASP.NET |
| Android native | Kotlin, Java | Android Studio, Jetpack Compose |
| iOS native | Swift | Xcode, SwiftUI |
| Cross-platform | Dart, JavaScript, Kotlin | Flutter, React Native, Kotlin Multiplatform |
| Hybrid | HTML, CSS, JavaScript | Ionic, Capacitor |
| Databases | SQL | MySQL, PostgreSQL, SQLite, Firebase, MongoDB |

## 8.1 Frontend, backend and full-stack

- **Frontend developer:** builds what users see.
- **Backend developer:** builds the server, database and APIs.
- **Full-stack developer:** does both.
- **Mobile developer:** builds apps for phones, usually working with a backend through APIs.

## 8.2 How to pick a first language

- Want websites? Start with JavaScript (after HTML and CSS).
- Want Android? Start with Kotlin (Java knowledge is a useful bonus).
- Want Android and iOS together? Start with Dart and Flutter.
- Not sure? Python or JavaScript are friendly for learning logic.
