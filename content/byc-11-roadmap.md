Here is the whole journey in one place. Follow the shared foundation first, then choose a path.

## 11.1 Shared foundation

1. Computer basics: hardware and software.
2. Computer OS and mobile OS.
3. Web vs mobile; how the internet works.
4. Frontend, backend, database and API concepts.
5. Types of mobile apps: native, cross-platform, hybrid.
6. Programming fundamentals and OOP.
7. Git, GitHub and the terminal.

## 11.2 Choose your path

**Web path**

1. HTML, CSS, JavaScript
2. Responsive design
3. React or Vue
4. Backend: Node.js or Laravel
5. SQL database, REST API
6. Hosting and deployment

**Android native path**

1. Java basics (optional)
2. Kotlin
3. Android Studio
4. Jetpack Compose
5. ViewModel, Room, Retrofit
6. Publish to Google Play

**Cross-platform path**

1. Dart language
2. Flutter widgets and layouts
3. State management (Provider, Riverpod, Bloc)
4. API and Firebase
5. Publish to Play Store and App Store

## 11.3 Which path is right for me?

| If you... | Choose |
|---|---|
| Like design and want quick visible results | Web (HTML, CSS, JavaScript) |
| Want to specialize in Android jobs | Kotlin + Jetpack Compose |
| Want Android and iOS with one skill | Flutter |
| Already know JavaScript | React Native or a web framework |
| Enjoy logic, data and servers | Backend development |

## 11.4 Sample 12-month study plan

| Months | Focus | Result |
|---|---|---|
| 1-2 | Foundation chapters, programming basics, Git | Solve small logic problems; first GitHub repository |
| 3-5 | Main language and path basics | Two small projects |
| 6-8 | Framework, API, database | App connected to a backend |
| 9-10 | Larger project, testing, UI polish | Portfolio project |
| 11-12 | Publish, write README, apply for internships or freelance | Live app or website, CV, portfolio |

> **Remember**
> Consistency beats intensity. One hour every day is better than ten hours once a month.
