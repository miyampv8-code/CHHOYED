You learn to code by building. Use projects to turn knowledge into skill.

## 12.1 Project ideas by level

| Level | Project ideas | Skills practiced |
|---|---|---|
| Beginner | Calculator, to-do list, personal profile page, unit converter | Variables, conditions, UI basics |
| Intermediate | Weather app using an API, notes app with a database, quiz app | API, JSON, local storage, lists |
| Advanced | Shopping app with login, cart and backend; chat app; booking system | Authentication, backend, state, deployment |

## 12.2 Learning habits that work

- Type the code yourself instead of only copying.
- Build small, finish, then improve.
- Read other people's code on GitHub.
- Join communities and study groups; teach others what you learn.
- Keep a notebook of errors and how you solved them.
- Never stop learning: testing, security, clean architecture, cloud services and AI tools.

## 12.3 Career paths

- Frontend, backend or full-stack web developer
- Android, iOS or Flutter developer
- QA tester / automation engineer
- UI/UX designer
- DevOps and cloud engineer
- Freelancer, startup founder or remote developer

> **Key idea**
> Your first project will not be perfect. That is normal. Every professional developer started with a simple, messy first app.
