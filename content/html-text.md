Text is the most common thing on a web page. HTML has special tags to mark headings, paragraphs and emphasis.

## Syntax

```html
<h1>Main heading</h1>
<p>A paragraph of text.</p>
```

There are six heading levels, from `<h1>` (most important) to `<h6>` (least important).

## Headings and paragraphs

```html
<h1>My School</h1>
<h2>About us</h2>
<p>We teach coding, math and physics.</p>
<h2>Contact</h2>
<p>Visit us any day of the week.</p>
```

> Use only one `<h1>` per page. Choose a heading by its **meaning**, not by its size. You can change the size later with CSS.

## Formatting text

| Tag | Meaning | Looks like |
|---|---|---|
| `<strong>` | Very important text | **bold** |
| `<em>` | Emphasized text | *italic* |
| `<br>` | Line break | starts a new line |
| `<hr>` | Horizontal line | a divider |

```html
<p>This is <strong>very important</strong> and this is <em>emphasized</em>.</p>
<p>First line<br>Second line</p>
<hr>
```

## Comments

A comment is a note for humans. The browser ignores it.

```html
<!-- This is a comment -->
```
