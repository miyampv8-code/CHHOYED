## How to learn here

- **Follow the lessons in order.** Each course page shows your progress.
- **Try the code yourself.** In the HTML, CSS and JavaScript lessons, press the **Try it** button on a code block, change the code and see the result at once.
- **Test yourself.** Most courses have a Practice page with questions and instant feedback.
- **Start from the beginning if you are new.** The course "Before You Code" explains computers, the web, apps and programming, so that every later lesson makes sense.

Your progress is saved only in your own browser. You do not need an account.
