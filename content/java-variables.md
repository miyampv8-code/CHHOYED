A variable stores a value. In Java you must say its **type**.

## Common types

```java
int age = 16;
double price = 2.5;
boolean isStudent = true;
char grade = 'A';
String name = "Dara";
```

`int` is a whole number, `double` a decimal, `boolean` true or false, `char` one character, and `String` is text.

## Using variables

```java
System.out.println(name + " is " + age + " years old");
```

`+` joins text and values together.

> A variable's type cannot change. Use `final` for a value that must never change: `final double PI = 3.14;`
